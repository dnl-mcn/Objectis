# Componente Button (v0.1.1)

Il componente `Button` trasforma un normale `div` in un elemento interattivo cliccabile.

## Utilizzo HTML

È sufficiente assegnare la classe `obj-button` a un elemento. Il `DomScanner` si occuperà del resto.

```html
<div class="obj-button" id="btn-save">Salva Modifiche</div>
```
